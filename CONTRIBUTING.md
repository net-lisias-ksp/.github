# How to help:


## The "Best" option

Fork this thing, edit files, pull request - all the usual jazz.

**Please use the `dev` branch** when available, `merge` otherwise and everything else fails, use `master` and I will handle the mess myself. 😃


## No github account?

Reach me on [Forum](https://forum.kerbalspaceprogram.com/).

I can accept code snippets on a comment there, but please align with me first and post the work under a Code Block inside a Spoiler (to avoid cluttering the pages):

![How to Contribute Forum](https://ksp.lisias.net/add-ons/how-to-contribute-forun.png)

No code snippets in private message, however. Your contributions must be public and adherent to [Forum Posting Guidelines](https://forum.kerbalspaceprogram.com/guidelines/) and [Add'On Posting Rules](https://forum.kerbalspaceprogram.com/topic/154851-add-on-posting-rules-april-13-2021/).

But I will not lie, I prefer you committing and doing pull requests here. 😃


## No Git; no Forum account?

I'm terribly sorry, but I'm afraid we will not be able to proceed.

I need (public) traceability in order to accept contributions in order to be able to correctly attribute the authorship.


# Guidelines:

1. **NO AI**.
    * By contributing to this project, you declare that you didn't used AI tools to generate any publishable artefact.
2. *Fair Use*, *Fair Dealing*, *Personal Usage*, every civilised country allows you to do a lot of things on copyrighted works as long it's used privately and not redistributed.
	* So I don't really care if you use AI or not, as long you don't commit on me anything it spits.
	* Use it for your own tools - as long they never leave your machine, you are fine.
	* Read more [here](https://forum.kerbalspaceprogram.com/topic/231697-ban-ai-generated-mods/page/3/#findComment-4538609).
3. Be **absolutely** sure I will hold you accountable for whatever you publish on my repositories.
	* Be sure to respect pertinent legislation about Copyrights, Intellectual Property and even Civil and Penal code both in USA as in your own Country.
		+ Since I'm Brazilian, I will evaluate your contributions under my local legislation too, as I'm legally responsible to whatever I commit or merge on there repositories.
4. When writing or translating, of course you can use dictionaries but, please, no Google Translator slop neither - use whatever the tool that will help you on the task, but please do it yourself.
	* Try to keep the tongue-in-cheek tone when possible - sometimes a English joke sounds bad in another language/culture, so fell free to replace these with something that looks good but is still funny in your language.
5. Follow the [Forum's Guidelines](https://forum.kerbalspaceprogram.com/guidelines/).
    * As a rule of thumb, if you can´t post something on Forum, you can't use it on a translation here neither.
6. Follow the [Add'On Posting Rules](https://forum.kerbalspaceprogram.com/topic/154851-add-on-posting-rules-april-13-2021/)
	* If you can't publish the code there, you can't commit the code here.


# Rationale

No one is questioning if AI is illegal (it's not, [at least for while](https://www.nytimes.com/2026/09/17/technology/microsoft-openai-publishing-industry.html)). 

I don't care if you use AI in your DayJob©. I don't care if you use AI in your own computer, *Fair Use*, *Fair Dealing* and *Personal Usage* are a thing. 

Live your life the way you want. Just be aware that people have the same right, and some of us don't cope very well on being coerced into using things we don't like - and a lot of users are saying no AI.

Besides that, [there're also practical reasons to avoiding AI](https://forum.kerbalspaceprogram.com/topic/231697-ban-ai-generated-mods/page/9/#findComment-4542526) on Open Source and Collaborative works:

* ***The Machine*** _is not intelligent_, you can't give it a task where reasoning is necessary and expect it to deliver good results without you feeding it back real, human Reasoning in the loop.
* ***The Machine*** _is not diligent_, it will not realise its own mistakes and warn you about. The damned thing can eventually detect **your** mistakes, but you can't expect it to self-correct without proper inputs from you.
* ***The Machine*** _is deceptive_, besides being unaware of it. The damned thing **really tries** to do right, but it fails on judging what's right by itself, it needs **YOU** to tell it what's right and, so, in the end anything it spits is merely **YOU** under a formal, more refined verbiage.
	+ ***The Machine*** will never be more competent than you, just faster on verbiage.
	+ *Most people think the AI is working because they can't tell when it isn't.*
* ***The Machine*** _is not deterministic_, the damned thing will spit different conclusions from the same input depending on how and when you feed it, due not only changes in the digested material but also daily internal changes on the weights used today (trimmed by human intervention - that "Data Annotation" thingy that I had yelled about).
* ***The Machine*** _is not unbiased_. It inherits the bias from your prompt and inputs.
* **It's demonstrated** that ***The Machine***, at least right now, is really useful on automation and code assisting (to a degree), but code generation is still a nightmare and there're documented [examples even on my own country at this time](https://www.reddit.com/r/brdev/comments/1x171gm/o_uso_da_ia_leva_a_uma_competi%C3%A7%C3%A3o_entre_os_devs/).
* **It's demonstrated** that the thing is increasing less useful to more experienced professionals, being even counter-productive for the most seasoned ones.
	+ [https://arxiv.org/abs/2507.09089](https://arxiv.org/abs/2507.09089)
		- Granted, this study needs to be reproduced using the latest (and more expensive) tools launched early this year.
		- But, still, newer models are hallucinating more then the older ones.
			- [https://arxiv.org/html/2505.23646v1](https://arxiv.org/html/2505.23646v1)
* **It's demonstrated** that excessive rely on AI causes cognitive deficit. Continuous use of AI makes you a **worse professional on the long run**, causing a dependency that may hinder your abilities - to a point that you will not be able to exercise the Critical Thinking that it's inherently needed while dealing with ***The Machine***.
	- [https://www.media.mit.edu/publications/your-brain-on-chatgpt/](https://www.media.mit.edu/publications/your-brain-on-chatgpt/)

The usefulness and even safeness of ***The Machine*** on a Modding scene like ours is debatable exactly because its best use cases happens on the workflows and pipelines that are beyound the reach of the common modder - unless you aim to transform this Scene into a walled garden where only professional developers paying for a full professional pipeline would act. And by now we need to discuss who is going to foot that bill and why.

This by any means aims to frame ***The Machine*** as useless or plain waste - there are Use Cases where it is really useful, and now and then the thing manage to really shine to a point it scares the *sheet* 😜 out of me.

But it is not there yet.
